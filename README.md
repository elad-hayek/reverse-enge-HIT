# Reverse Engineering Course Project

This project is a research-based submission scaffold for the Spring 2026
Reverse Engineering course assignment.

## Deliverables

- `reverse_engineering_report.md` - main English report.
- `sources/source_manifest.md` - source register with retrieval dates.
- `ai/ai_usage_log.md` - AI-use and verification record.
- `images/` - required screenshot and diagram placeholders.
- `submission_checklist.md` - two-person delivery and archive structure.

## Before Submission

1. Fill in the student metadata table at the top of the report.
2. Replace each image placeholder with a genuine screenshot or original diagram.
3. Export the final report to DOCX or ODT. The syllabus says not to submit the
   main report as PDF.
4. Save a complete PDF or full-page screenshot of each cited source separately.
5. Review every citation and technical claim manually.
6. Follow `submission_checklist.md` when preparing the email attachments and
   source archive.

No malware binaries, compiled ransomware, exploit code, credentials, or live
command-and-control indicators are included in this workspace.
